# Reference

Look up the interfaces and constraints implemented by this version of the client.

- [CLI reference](../cli.md): commands, options, environment variables, and exit codes.
- [Python API reference](../python-api.md): clients, endpoint functions, and responses.
- [Event model reference](events.md): shared fields, event payloads, and routing.

- [Bundled OpenAPI YAML](../c4/class/schemas/openapi.yaml): downloadable schema bundle.

The OpenAPI header requirement and the Python/CLI optional argument differ;
see [routing](events.md#routing) before omitting a Kafka topic.
