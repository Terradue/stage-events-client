Stage Events Client

stage-events-client sends workflow events to the Stage Events HTTP API. Use its Python library for synchronous or asynchronous applications, or the optional send-stage-event command for shell scripts and workflow steps. The package provides validated models for nine event types and sends them as JSON with the application/cloudevents+json content type.

Python 3.10 or newer is required. Sending to a deployed service requires its endpoint URL and, when enabled, a bearer token. The introductory tutorial runs locally without a service or credentials.

Install

For the Python library:

python -m pip install stage-events-client

For the library and command-line interface:

python -m pip install 'stage-events-client[cli]'

The client publishes events over HTTP. It does not provide an event receiver, Kafka consumer, workflow scheduler, or service deployment.
